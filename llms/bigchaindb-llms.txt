# BigchainDB

> BigchainDB is an open-source blockchain database that combines high throughput, low latency, immutable data storage, powerful full-text query and built-in asset support with decentralized (Byzantine fault-tolerant) control. It is developed by BigchainDB GmbH (Berlin), with the IPDB Foundation overseeing the software and public networks. Applications sign transactions with Ed25519 crypto-conditions and read/write them over a simple versioned HTTP API on each node (default port 9984).

## APIs
- [BigchainDB HTTP API](https://docs.bigchaindb.com/projects/server/en/latest/http-client-server-api.html): Node client-server API for creating and reading transactions, assets, outputs, metadata, blocks and validators (base path /api/v1).

## Specs
- [OpenAPI (generated)](openapi/bigchaindb-http-openapi.yml): Faithful transcription of the documented HTTP endpoints, generated by the API Evangelist pipeline.
- [Data model / ERD](data-model/bigchaindb-data-model.yml): Asset / Transaction / Input / Output / Metadata / Block / Validator entity graph.
- [Error catalog](errors/bigchaindb-problem-types.yml): Documented 400 / 404 responses and the JSON error envelope.
- [Conventions](conventions/bigchaindb-conventions.yml): Auth model, content-addressed idempotency, write modes, limit-based search paging.
- [Authentication](authentication/bigchaindb-authentication.yml): Payload-level crypto-conditions signing model.
- [Conformance](conformance/bigchaindb-conformance.yml): Crypto-Conditions, Ed25519, IPLD, Tendermint BFT.
- [Lifecycle](lifecycle/bigchaindb-lifecycle.yml): URI-path versioning (v1); successor project Planetmint.
